# Skill: vv-quiz-funnel
# Vital Vision Shop — Quiz Funnel Content Generator

---

## Purpose
Generate compliant organic content specifically designed to drive traffic to the
Vital Vision 60-second wellness quiz. Content types include: quiz-driver captions,
story sequences, quiz explainer posts, and result-page copy directions.
All output is saved as drafts. Nothing is published automatically.

---

## When to Use
- When the content calendar has a quiz-funnel slot (Tue/Sun in week-01 plan)
- When launching a new quiz push or awareness campaign
- When building a story sequence to warm up the audience before a quiz CTA
- When writing copy for the quiz result recommendation pages

---

## Inputs
- Content type: Instagram caption / Story sequence / Facebook post / Reel script / Result page copy
- Persona (optional): Maya (28–42, busy professional) / Jordan (22–35, aesthetic-driven)
- Angle: Curiosity / Simplicity / Overwhelm / Identity / Honesty
- Goal: Quiz starts / Brand awareness / Trust building

- Saved to: automations/drafts/YYYY-MM-DD-[content-type]-quiz-funnel.md

## Safety and Compliance Rules

- Never use the paid quiz URL (finder-quiz-15203) in organic content
- Quiz-driver copy may reference how someone *feels* but never name a medical condition
- "Tired," "overwhelmed," "off" are lifestyle feelings — compliant
- "Anxiety disorder," "insomnia," "IBS" as conditions being targeted — not compliant
- Result page copy must use structure/function language only
- "Results may vary" required on any post where a quiz result or product benefit is mentioned
- No guaranteed outcome implied by quiz result ("this will fix you" — never)
