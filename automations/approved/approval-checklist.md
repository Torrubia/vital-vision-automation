# Human Approval Checklist — Vital Vision Shop

Before any content is published, confirm:

## Brand
- [ ] Matches Vital Vision tone: premium, calm, modern, trustworthy
- [ ] Product name is correct
- [ ] Visual style matches brand colors
- [ ] CTA is clear

## Compliance
- [ ] No disease claims
- [ ] No cure/treat/prevent language
- [ ] No guaranteed results
- [ ] No medical diagnosis language
- [ ] No aggressive fear-based copy
- [ ] Uses soft support language

## Funnel
- [ ] Link goes to correct destination
- [ ] Quiz link works
- [ ] Product page link works
- [ ] CTA matches campaign goal

## Platform
- [ ] Caption fits Instagram/Facebook
- [ ] Visual size is correct
- [ ] Hashtags are relevant
- [ ] No restricted claim in image text

## Approval
- [ ] Reviewed by human
- [ ] Approved for publishing
- [ ] Saved final version
