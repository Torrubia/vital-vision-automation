# Archive — Vital Vision Automation Legacy Files

This directory preserves deprecated files for historical reference and audit trail.

Do not use any file in this directory for new development.

Archived: 2026-08-26

## Subdirectories

| Directory | Contents |
|---|---|
| `vqb-scripts/` | Deprecated Visual Quiz Builder (VQB) API automation scripts |
| `vqb-config/` | Deprecated VQB API configuration and infrastructure docs |
| `vqb-copy/` | VQB-era product copy — reusable content, archived for reference |
| `vqb-automations/` | VQB API update drafts and approval records |
| `old-skills/` | Superseded skill files replaced by `.claude/skills/` system |

## Why These Files Are Archived

The Visual Quiz Builder (VQB) API workflow is deprecated.
The new architecture is built around Shopify, Claude Code agents, and skills.
All active functionality has been migrated to the new system or will be in subsequent phases.

## Recovery

All files here are preserved in full. If recovery is ever needed, move the file
back to its original location and restore references in package.json and agent files.
