# Swipe Rules

## Purpose
Define safe rules for reverse engineering without copying.

## Allowed
- Study structure
- Study format
- Study content rhythm
- Study hooks by category
- Study CTA patterns
- Study comment themes

## Not Allowed
- Copy exact words
- Copy designs
- Copy testimonials
- Copy product claims
- Copy brand visuals
- Copy medical promises

## Vital Vision Rule
Every insight must be rewritten through:
1. Brand voice
2. Compliance framework
3. Product library
4. Lucy approval
