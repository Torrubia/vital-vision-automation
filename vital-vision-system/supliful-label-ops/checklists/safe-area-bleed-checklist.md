# Safe Area and Bleed Checklist

Zoom in on each panel before checking. Do not rely on a thumbnail view.

## Safe Area Checks

The safe area is the inner boundary within which all important text and logos must sit.
Content outside the safe area may be clipped when the label is printed and applied to a bottle.

- [ ] Product name is fully within the safe area (no letters near the edge)
- [ ] Product subtitle / tagline is within the safe area
- [ ] Key benefit statements are within the safe area
- [ ] Logo is fully within the safe area
- [ ] All Supplement Facts text is within the safe area
- [ ] Suggested Use text is within the safe area
- [ ] Caution / Warning text is within the safe area
- [ ] FDA disclaimer text is within the safe area
- [ ] Manufacturer address is within the safe area
- [ ] Net quantity text is within the safe area
- [ ] No element that contains legally required information sits on or beyond the safe area boundary

---

## Bleed Area Checks

The bleed area is the outermost zone that extends beyond the safe area to the edge of the label.
Background images and color fills should extend into the bleed area, but text and logos should not rely on the bleed area.

- [ ] Background color or image extends to or past the bleed boundary (no white gaps at label edges)
- [ ] No critical text is placed in the bleed area only (it would be cut off)
- [ ] No logo is placed in the bleed area only
- [ ] Decorative elements in the bleed area are acceptable to be partially trimmed

---

## Matrix Code / Barcode Zone Checks

The matrix code zone is a reserved area that Supliful uses for tracking or regulatory barcodes.
This zone must remain clear of any text, images, or design elements.

- [ ] Matrix code / barcode is visible and unobstructed
- [ ] No text overlaps the matrix code zone
- [ ] No image or gradient covers the matrix code zone
- [ ] Matrix code appears dark on a light background (not reversed or illegible)
- [ ] If a QR code is present, it is fully within its designated zone and not partially covered

---

## Panel Separation Checks

- [ ] Front panel boundary is clear — no back panel content bleeds into the front panel area
- [ ] Back panel boundary is clear — no front panel content bleeds into the back panel area
- [ ] If there is a side panel, its content is within its own boundary
- [ ] Panel boundaries align with the Supliful template guidelines
