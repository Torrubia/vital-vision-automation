# Pre-Publish Checklist

Use this checklist before a Vital Vision product goes live on Shopify with a new or updated label.
This covers both the Supliful label status and the Shopify product page status.

**Product:** ___________________________
**Date:** ___________________________
**Going live:** Yes — this is a final check before the product is visible to customers

---

## Label Status

- [ ] Label has been reviewed using Workflow 01 or 02
- [ ] QA Label Reviewer issued a SAVE decision
- [ ] Save Label Approval Checklist (Workflow 03) was completed
- [ ] Label was saved in Supliful successfully
- [ ] Save was logged in `logs/`
- [ ] Label version noted: ___________________________

---

## Shopify Product Page

- [ ] Product title matches the label: ___________________________
- [ ] Product description uses only approved, compliant language
- [ ] Product description does not contain stronger claims than the label
- [ ] FDA disclaimer or equivalent is present in the product description or a visible page section
- [ ] Product images show the correct label version (updated if label changed)
- [ ] Variant details (quantity, size) match the label net quantity
- [ ] Product price has been reviewed and set correctly
- [ ] Product is set to the correct product type and tags

---

## Shopify-Supliful Connection

- [ ] Supliful product is connected to the correct Shopify product
- [ ] Fulfillment is routed through Supliful (not manual if Supliful is the supplier)
- [ ] Shipping rules are correct for the product type

---

## Compliance Final Check

- [ ] All claims on the Shopify page reviewed and confirmed compliant
- [ ] No disease-treatment language on the Shopify page
- [ ] FDA disclaimer is accessible to the customer (on product page or in footer/policy page)
- [ ] "These statements have not been evaluated..." statement is present somewhere visible

---

## Final Review Before Going Live

- [ ] Shopify product page preview reviewed
- [ ] Product looks professional and premium
- [ ] Mobile view checked (product images and description readable on mobile)
- [ ] Add to Cart button works
- [ ] Checkout flow works (if applicable to test)

---

## Post-Publish Steps

After the product goes live:

- [ ] Confirmed the product is live on the Shopify storefront
- [ ] Checked that the product page looks correct
- [ ] Logged the go-live action in `logs/[date]-[product]-published.md`
- [ ] Note if any issue was found after going live and initiate Workflow 07 if needed
