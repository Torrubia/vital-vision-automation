# Supplement Facts Checklist

Use this checklist while reading the Supplement Facts panel on screen in the Supliful editor.
Read each row of the table carefully. Do not check any item without confirming it visually.

**Product:** ___________________________
**Date:** ___________________________

---

## Panel Structure

- [ ] Supplement Facts header is present and visible at the top of the panel
- [ ] Serving size is stated (e.g., "Serving Size: 2 Capsules")
- [ ] Servings per container is stated (e.g., "Servings Per Container: 30")
- [ ] A horizontal rule / divider separates the header from the ingredient columns
- [ ] Column headers are present: Amount Per Serving | % Daily Value
- [ ] A bold divider appears between the header section and the ingredient rows

---

## Ingredient Rows

For each ingredient in the formula, confirm:

- [ ] Ingredient name is spelled correctly
- [ ] Ingredient name is not cut off or truncated
- [ ] Amount per serving is listed (e.g., "200 mg")
- [ ] Unit of measure is appropriate (mg / mcg / IU / CFU / etc.)
- [ ] % Daily Value column is filled in (number) or marked with "†" where no DV is established
- [ ] Sub-ingredients (if in a proprietary blend) are listed below the blend name and indented

---

## Daily Value Footnotes

- [ ] "†" footnote is present if any ingredient uses "†" in the DV column
- [ ] Footnote text reads: "† Daily Value not established."
- [ ] If % DVs are based on a specific age/gender/calorie level, that is noted

---

## Specific Product Checks

### Inner Balance (Complete Multivitamin)
- [ ] All vitamins listed: A, C, D, E, K, and B vitamins (B1, B2, B3, B5, B6, B7, B9, B12)
- [ ] All minerals listed that are included in the formula
- [ ] All amounts match the product specification

### Inner Bloom (Advanced Probiotic Formula)
- [ ] Probiotic strains listed with their full scientific names
- [ ] CFU count stated (e.g., "10 Billion CFU")
- [ ] "at time of manufacture" notation present if applicable
- [ ] Prebiotic ingredient listed if included

### Inner Calm (Magnesium Glycinate)
- [ ] Magnesium amount stated in mg
- [ ] Form of magnesium stated (Glycinate / Bisglycinate / as Magnesium Glycinate)
- [ ] % Daily Value for Magnesium present

### Inner Grow (Hair, Skin & Nails Support)
- [ ] Biotin listed with amount in mcg
- [ ] Collagen or Keratin listed if included
- [ ] Other key ingredients (Zinc, Vitamin C, etc.) listed with amounts

---

## Other Ingredients Section

- [ ] "Other Ingredients:" line is present below the Supplement Facts table
- [ ] Capsule type listed (e.g., "Hypromellose (Vegetable Capsule)")
- [ ] Fillers or flow agents listed (e.g., "Magnesium Stearate," "Silicon Dioxide")
- [ ] No allergens present that are not disclosed (review for gluten, soy, dairy, tree nuts if applicable)
- [ ] "Free from" claims (if any) are accurate based on the ingredient list
