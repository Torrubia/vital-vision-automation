# Product-Line Consistency Checklist

Use this checklist when comparing two or more Vital Vision product labels to check family consistency.
Complete while looking at all labels side by side on screen.

**Products being compared:** ___________________________
**Date:** ___________________________

---

## Product Name Treatment

Look at the product name on each label and compare:

- [ ] Same font family used across all products
- [ ] Same font weight used across all products
- [ ] Same capitalization rule used across all products (ALL CAPS / Title Case / other)
- [ ] Product names are visually similar in size relative to the label
- [ ] Same color used for product name on all products (or a predictable variation)

## Subtitle Treatment

- [ ] Same font style for subtitle across all products
- [ ] Same size relationship between product name and subtitle across all products
- [ ] Same vertical positioning of subtitle relative to product name

**Inconsistencies found:**

---

## Logo Placement

- [ ] Logo is in the same zone (corner/center) on all labels
- [ ] Logo is the same version (correct light or dark variant for each background) on all labels
- [ ] Logo is approximately the same visual size relative to the label on all products

**Inconsistencies found:**

---

## Background and Color

- [ ] All products use background colors that feel related (same family palette, consistent tone)
- [ ] If product-line differentiation colors are used, they feel like a deliberate system (not random)
- [ ] No single product's colors look dramatically different from the others

**Inconsistencies found:**

---

## Benefit Claims Format

- [ ] All products use the same format for benefits (bullet / icon + text / stacked lines)
- [ ] Roughly same number of benefit statements on front panel across products
- [ ] Same font and size for benefit text across products
- [ ] Same tone and language register (all use the same level of softness / directness)

**Inconsistencies found:**

---

## Supplement Facts Table

- [ ] All products use the same table format style
- [ ] Same font size for Supplement Facts across all products
- [ ] Same border style (ruled / no border / boxed)
- [ ] Same column width ratios (ingredient name : amount : % DV)

**Inconsistencies found:**

---

## Legal Text and Required Elements

- [ ] FDA disclaimer appears in the same position on all labels
- [ ] FDA disclaimer uses the same font size on all labels
- [ ] Manufacturer address appears in the same position on all labels
- [ ] Suggested Use section uses the same style header on all labels
- [ ] Caution / Warning section uses the same style on all labels

**Inconsistencies found:**

---

## Overall Family Cohesion

Look at all labels together:

- [ ] The product family reads as a unified brand at a glance
- [ ] A shopper could identify these as the same brand without reading the text
- [ ] The family has a consistent mood and premium feel across all products
- [ ] No single product feels dramatically more or less premium than the others

**Overall family cohesion: STRONG / MODERATE / WEAK**
