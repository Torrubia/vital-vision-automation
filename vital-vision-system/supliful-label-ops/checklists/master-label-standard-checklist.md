## Layout Grid Compliance

- [ ] Product name is in the approved product name zone (position matches standard)
- [ ] Subtitle is in the approved subtitle zone
- [ ] Benefit claims are in the approved benefit zone
- [ ] Logo is in the approved logo zone
- [ ] Logo size matches the standard (minimum size met, not oversized)
- [ ] Logo clearance zone is respected (nothing too close to the logo)
- [ ] Supplement Facts table is in the approved zone on the back panel
- [ ] Suggested Use is in the approved position
- [ ] Caution / Warning is in the approved position
- [ ] FDA disclaimer is in the approved position
- [ ] Address is in the approved position
- [ ] Internal gutter spacing between sections matches the standard

---

## Product-Line Differentiation

- [ ] This product's accent color matches the approved product-line color for this product
- [ ] Any product-specific icon or botanical element matches the approved version
- [ ] The label is visually distinguishable from other Inner products while still being part of the family

---

## Legal and Compliance Text

- [ ] FDA disclaimer text is the exact standard wording
- [ ] FDA disclaimer font and size meet the standard minimum
- [ ] Manufacturer address matches the approved address on file
- [ ] Suggested Use text is approved and compliant

---

## Supliful Constraints

- [ ] All text inside safe area
- [ ] Background to bleed edge
- [ ] Matrix code zone clear
