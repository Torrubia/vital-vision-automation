## Scoring Guide

| Score | Meaning |
|---|---|
| 5 | Excellent — exceeds the standard; this element is a strength |
| 4 | Good — meets the standard; no change needed |
| 3 | Adequate — functional but not premium; improvement would help |
| 2 | Below standard — noticeable problem; improvement required |
| 1 | Poor — significant failure; must be fixed before saving |
