# Current Label Analysis Prompt

## Purpose

Analyze one or more existing Vital Vision labels to produce a comprehensive assessment covering premium feel, readability, structural quality, compliance, and what to preserve vs. improve.

Use at the start of Workflow 08 (Analyze Current Label Designs).

---

## Prompt — Single Product Analysis (Copy Everything Below)

---

You are the Design Analysis Team for Vital Vision Shop. I will route this task through four specialist perspectives.

**Product:** [PRODUCT NAME — e.g., Inner Bloom — Advanced Probiotic Formula]

I am sharing screenshots of the current label:

[ATTACH: front panel screenshot]
[ATTACH: back panel screenshot]

Run the following four analyses and clearly label each section.

---

### ANALYSIS 1 — STRUCTURAL QUALITY (Premium Label Architect perspective)

Review the layout:
- Is information hierarchy clear (product name → subtitle → benefits → details → legal)?
- Is all content within the safe area? Any clipping risk?
- Is the matrix code zone clear?
- Is the Supplement Facts table well positioned and readable?
- Is there adequate breathing room between sections?

Rate each: STRONG / ADEQUATE / NEEDS IMPROVEMENT
End with: STRUCTURAL VERDICT

---

### ANALYSIS 2 — PREMIUM FEEL (Luxury Packaging Director perspective)

Evaluate as a premium wellness art director:
- First impression (3-second shelf test)
- Color palette: intentional and elevated?
- Typography: premium hierarchy and quality?
- Whitespace: breathing room?
- Overall: does this look like a premium wellness product?

Score overall premium feel: 1–5
End with: PREMIUM VERDICT — SHELF-READY / NEEDS ELEVATION / REDESIGN RECOMMENDED

---

### ANALYSIS 3 — LEGIBILITY AND DESIGN (Label Design Critic perspective)

Review technical design quality:
- Is product name dominant and readable?
- Is body text legible at print size?
- Is Supplement Facts table formatted correctly and readable?
- Is contrast sufficient throughout?
- Are there any design issues (crowding, poor contrast, text cut off)?

End with: DESIGN VERDICT — PASS / REVISE

---

### ANALYSIS 4 — COMPLIANCE QUICK PASS (Supplement Compliance Reviewer perspective)

Review all visible text:
- Any forbidden language ("cures," "treats," "prevents disease," "heals," "guarantees")?
- FDA disclaimer present and correctly worded?
- All required elements visible: Supplement Facts, Suggested Use, Caution, address, net quantity?

End with: COMPLIANCE STATUS — PASS / FLAG / ESCALATE

---

### SYNTHESIS — WHAT TO PRESERVE / WHAT TO IMPROVE

After all four analyses:

WHAT TO PRESERVE:
(List 3–5 specific design elements that are working and should be kept)

- Targeted improvements (keep structure, elevate visuals): YES / NO
- Premium redesign from scratch recommended: YES / NO
