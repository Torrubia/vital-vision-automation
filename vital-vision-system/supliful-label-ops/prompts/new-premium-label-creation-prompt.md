# New Premium Label Creation Prompt

## Purpose

The master copy-paste prompt for creating a complete new premium Supliful-ready label for a Vital Vision product. Paste this into Claude with a completed design brief and product data. The output is a complete design package: strategy, layout spec, copy blocks, color and typography direction, and Supliful build instructions.

Use at Step 7 of Workflow 09 (Create Premium Label from Scratch).

---

## Output Required

Produce the following sections in order. Label each clearly.

### SECTION 1 — LABEL STRATEGY
What this label should communicate. The story, the feeling, the positioning. One paragraph.

### SECTION 2 — LAYOUT SPECIFICATION
Complete layout spec from the Premium Label Architect:
- Front panel zones (logo, product name, subtitle, benefits, net quantity)
- Back panel zones (Supplement Facts, Suggested Use, Caution, FDA disclaimer, address, matrix code)
- Spacing rules
- Font size minimums at print scale
- Safe area and bleed notes

### SECTION 3 — CREATIVE DIRECTION
From the Luxury Packaging Director:
- Color direction (palette, hex recommendations or descriptions, rationale)
- Typography direction (font personality, weight for product name, hierarchy notes)
- Visual element direction (icon, botanical, purely typographic)
- Premium positioning brief (how this label communicates quality)

### SECTION 4 — COMPLETE COPY BLOCKS
All approved copy organized for the Supliful dashboard build:

## Important Rules

- Do NOT deviate from the Vital Vision brand identity.
- All benefit copy must use only compliant language: "supports," "helps support," "may help support," "helps maintain."
- Never include disease-treatment language.
- The FDA disclaimer must appear exactly as: "These statements have not been evaluated by the Food and Drug Administration. This product is not intended to diagnose, treat, cure, or prevent any disease."
- If any Supplement Facts data looks incorrect or incomplete, flag it with ⚠️ VERIFY before including it.

Begin with SECTION 1.
