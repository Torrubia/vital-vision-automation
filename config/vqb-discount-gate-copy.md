## Purpose

The discount gate is the screen that appears after email capture and before the product result.
Its job is to:
1. Reward the user for submitting their email.
2. Build anticipation for the product result.
3. Be functional and brief — not a distraction from the result.

---

## Current Issue

The discount code screen currently appears BEFORE the product result card,
which may cause users to focus on the code and miss the personalized recommendation.
The screen is visually heavy and may feel like a pause in the flow.

---

## Recommended Approach

- Keep the discount screen SHORT and FUNCTIONAL.
- Use it as a bridge, not a destination.
- The primary message: "Your code is ready — your result is just below."
- One clear next action: proceed to the product result.

## Design Notes

- Code should display in a clearly bounded box (not inline text).
- Use a monospace or bold font for the code itself.
- Code box should have a subtle border or background — not a heavy colored block.
- Do NOT use a large hero image on this screen — keep it compact.
- Screen must fit in one mobile viewport — no scroll required to reach the CTA.
- CTA button: full-width on mobile, brand primary color.

---

## What NOT to Include on the Discount Screen

- Product images (save for the result card)
- Long benefit descriptions
- Multiple CTAs
- Pop-up or modal overlays
- Countdown timers (creates unnecessary anxiety)
- Social proof or testimonials (wrong moment — save for result card)

---

## Flow Context

```
Email submitted
  → Discount screen (this screen)
      - Code displayed clearly
      - Single CTA to proceed
  → Product result card
      - Full personalized recommendation
      - "Why This Match?"
      - Primary shop CTA
```
