# Safety Rules — Vital Vision Automation

## Default Mode
AUTO_PUBLISH=false
REQUIRE_HUMAN_APPROVAL=true

## Human Approval Required For
- Social posts
- Facebook/Instagram captions
- Reel scripts
- Canva briefs
- Ad copy
- Email marketing copy
- Shopify product page copy
- Any content mentioning supplements or wellness benefits

## Never Do Automatically
- Publish to Facebook
- Publish to Instagram
- Send emails to customers
- Edit Shopify live theme
- Change product claims
- Spend ad budget
- Connect new APIs
- Expose tokens or API keys

## Compliance Rules
Use soft wellness language only.

Allowed examples:
- may support
- supports overall wellness
- helps maintain
- designed to support
- daily wellness routine

Avoid:
- cure
- treat
- prevent
- diagnose
- guaranteed results
- FDA approved
- reverses hair loss
- fixes anxiety
- heals gut disease

## Required Workflow
Generate draft → save draft → human review → approve → publish manually.
